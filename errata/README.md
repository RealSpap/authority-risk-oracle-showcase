# Errata

A correction to something this repository, its data or its public texts said, or something I said in a public thread about this work. One file per correction, named `E-<date>-<subject>.md`. A published statement is never edited or removed to hide the error: the entry says what was said, what is true, the cause, how to replay it, and what is not established.

## How to report an error

Write to contact@realspap.com, or open an issue on this repository. Give the place concerned, the statement, and what supports your reading (a transaction, a block number, an address with the network and the call to make, a line of code or a public document), so that anyone can read it again. Nothing private belongs in an issue. No delay of reply is promised.
